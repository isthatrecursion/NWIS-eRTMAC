# Five-minute demonstration

Before the presentation, run `./Start-Demo.ps1` from the project root and open `http://127.0.0.1:8765/#brief`. Use connected SYNTHETIC mode. Keep `docs/demo_media/backup-demonstration.mp4` available if the browser fails. That video renders recorded API facts in an illustrative display.

| Time | Action | Explain |
|---|---|---|
| 0:00–0:40 | Show default Next Interval Brief, active synthetic well, formation and distance | Start with the evidence sentence and visible live freshness. All telemetry here is simulation. |
| 0:40–1:20 | Press Historical Elevated in controlled failure controls; open Why/evidence | Two supporting offset wells, two verified clean crossings; support and counter remain distinct. Open an event's source page. |
| 1:20–2:05 | Press Stale flow-out | Depth continues to 2480 m. Historical state stays Elevated; fresh live corroboration is incomplete and no Warning is allowed. |
| 2:05–2:40 | Press Restore fresh signals; acknowledge the active alert; press Passed interval | Sustained valid signals permit Warning, acknowledgement records the action, and the passed interval resolves it. RESET returns the same run to the start. |
| 2:40–3:20 | Open map/compare and secondary modules | Surface ranking can differ from target-depth ranking; formation alignment includes uncertainty. Secondary risks show partial maturity; mud loss is the polished slice. |
| 3:20–4:05 | Ask “Show mud loss evidence in TIPAM”, then open Sources | Structured evidence first, deterministic tool chain, numeric verification, facts/computed/interpretation/gaps. Historical quotations cannot issue tool instructions. Unsupported questions or missing history return limitations. |
| 4:05–5:00 | Open Validation | Frozen predictions, four baselines, two hits, a miss and a false warning. Forty synthetic reference pages include scans and extraction failures. Independent human sign-off and field validation are pending. |

Rehearse without internet using `./Prepare-Offline.ps1 -InstallFromCache`. The prebuilt frontend needs no Node process during the demo. Do not show synthetic benchmark metrics as calibrated field performance. Stop the server with Ctrl+C; start again for a newly seeded replay or use RESET for the current run.
